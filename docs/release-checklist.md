# Release checklist

確認日と確認者を記録し、実施していない項目は「未確認」のまま残す。

## 問題体験

- [ ] 結論モードselectorが表示され、初期値が自動表示である
- [ ] 組み込み問題＋自動表示／クイズを確認する
- [ ] 自由問題＋自動表示／クイズを確認する
- [ ] クイズは統合前提段階に表示される
- [ ] クイズ未回答・誤答では「結論」ボタンがdisabledである
- [ ] クイズ正答後に「結論」ボタンがenabledになる
- [ ] 正答だけでは結論段階へ移動せず、ボタン操作後に移動する
- [ ] 結論段階にはクイズcontrolがなく、結論文と結論図を表示する
- [ ] 自動表示では結論図を直ちに表示する
- [ ] 自動表示では統合前提完成後に「結論」ボタンがenabledである
- [ ] 自動配置＋automatic／quizを確認する
- [ ] 手動配置＋automatic／quizを確認する
- [ ] 手動結論配置が結論段階で操作できる
- [ ] 保存済み自由問題を両方の結論モードで開く
- [ ] 統合前提段階で自動表示／クイズを切り替える
- [ ] 組み込み問題に項割当てクイズが表示されない
- [ ] 組み込み問題の統合前提段階で結論クイズが表示される
- [ ] 組み込みinvalid問題で「確定した結論なし」を回答できる
- [ ] 自由問題で二つの前提を入力できる
- [ ] 自由問題のautomaticではクイズなし、quizでは統合前提段階にクイズが表示される
- [ ] 現実には偽の前提でも形式どおりの結果が導出される
- [ ] 自由invalid問題で「確定した結論なし」を表示する
- [ ] 前提の事実的な真偽を判定しない説明が表示される
- [ ] 問題種別の切替で結論クイズと導出結果の状態が混ざらない
- [ ] 保存済み自由問題が実験モードで開く
- [ ] 手動駒配置が組み込み問題・自由問題の両方で動く
- [ ] 日本語・英語、320px幅、200%拡大、キーボード、`file://` を確認する

## 多言語ユーザー登録名詞（v2）

- [ ] 日本語だけ／英語だけ／日英両方でユーザー登録名詞を登録する
- [ ] 英語の片側だけを入力するとエラーになる
- [ ] 日本語のみの項を英語表示、英語のみの項を日本語表示する
- [ ] fallback通知が表示され、翻訳追加後に消え、翻訳削除後に戻る
- [ ] 翻訳不足の保存問題を両言語で開く
- [ ] version 1 localStorage移行とversion 1 backup importを確認する
- [ ] version 2 backup exportを確認する
- [ ] IMEで「田中」を入力する
- [ ] 320px、200%拡大、キーボード、`file://` を確認する
- [ ] 日本語画面の全空欄時は日本語名詞句だけを要求する
- [ ] 英語画面の全空欄時は英語二欄だけを要求する
- [ ] validationメッセージが一回だけ表示される
- [ ] 利用者向け文面に曖昧な「ラベル」を使わない
- [ ] 英語片側入力時に組合せエラーを表示する
- [ ] validation後に最初に修正すべき入力へfocusする
- [ ] ゲーム画面にはユーザー登録名詞件数と管理ボタンだけが表示される
- [ ] 100件でもメイン図との距離が増えない
- [ ] 管理画面を開き、ゲーム画面へ戻れる
- [ ] 開閉でゲーム段階、駒配置、クイズ回答が維持される
- [ ] 管理画面で追加、編集、削除できる
- [ ] 使用中名詞の削除制約が維持される
- [ ] locale切替後も管理画面に留まる
- [ ] 管理画面のIMEで「田中」を入力する
- [ ] 管理入口と管理見出しのfocus往復を確認する
- [ ] 管理画面を320px、200%拡大、キーボード、`file://` で確認する
