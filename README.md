# ルイス・キャロルの論理ゲーム

ルイス・キャロルの『記号論理学』で説明されているゲームをブラウザで楽しめるようにしました。
ゲームの作成にあたって、主に以下の文献を参照しました。 

Lewis Carroll, *Symbolic Logic, Part I: Elementary*, 4th ed.,  Macmillan, 1897.

結論をクイズ形式で回答する機能や、利用者が自由に問題を 作成する機能があり、日本語と英語の両方に対応しています。

## 利用モード

### 問題

- **組み込み問題**：固定された二つの前提を使用します。
- **自由問題**：利用者が二つの前提を入力します。ユーザーが登録した名詞も利用できます。

### 図

- **自動表示**：前提と結論の図を自動で表示します。
- **手動駒配置**：セル内や境界上へ自分で駒を配置します。論理上の位置と駒の種類が正しい場合に次へ進めます。

### 結論 

- **自動表示**：統合した前提から導かれる結論を自動で表示します。
-  **クイズ**：前提から導かれる結論を回答します。正解すると結論の図へ進めます。


## データ保存・書き出し・読み込み

複数の自由問題に名前を付け、ブラウザに保存できます。
ユーザー登録名詞一覧もブラウザに保存されます。
ユーザー登録名詞と保存済み自由問題は、JSONファイルへ書き出せます。
バックアップの書き出しと読み込みは、それぞれindex.htmlの下部にある、「バックアップの保存」と「バックアップの復元」ボタンをクリックすることで実行されます。

## チュートリアル

 `tutorial.html` では、ルイス・キャロルの論理ゲームで使用される記号や駒の移動規則について説明します。

## 必要環境

ゲームの利用にはブラウザのみが必要です。開発時には Node.js と npm が必要です。

動作確認には Google Chrome を使用しています。

## ゲームの起動方法

### 通常の利用者

GitHubの「Releases」から配布用ZIPファイルをダウンロードして 展開してください。 展開したフォルダー内の `index.html` をダブルクリックすると ゲームが起動します。遊び方を確認する場合は、 `tutorial.html` をダブルクリックしてください。 開発環境の用意やコマンドの実行は必要ありません。

### ソースコードから起動する場合

 GitHubの「Code」からダウンロードしたソースコードには、 ビルド済みの `dist` フォルダーは含まれていません。 次のコマンドで配布ファイルを生成してください。

```sh
npm ci
npm run build
```

生成後、`dist/index.html`を開いてください。

## セットアップと開発 (エンジニア向け)

```sh
npm install
npm run dev
```

開発用 URL はコンソールに表示されます。TypeScript の変更は監視されますが、HTML または CSS を変更した場合は開発コマンドの再起動が必要な場合があります。

### 検証

```sh
npm test
npm run typecheck
npm run build
npm run check
```

`npm run check` は型検査、テスト、ビルドを順に実行します。

### 配布

`npm run build` で `dist/` に配布物を生成します。生成された `dist/index.html` と `dist/tutorial.html` をブラウザで直接開いて利用できます。外部ネットワークへの接続やローカルサーバーは不要です。
