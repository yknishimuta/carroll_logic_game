# ルイス・キャロルの論理ゲーム

ルイス・キャロルの図式を使い、二つの前提から導かれる結論を考えるブラウザゲームです。
問題作成、図への駒配置、結論判定をそれぞれ自動またはクイズ形式で楽しめます。
日本語と英語の両方に対応しています。

## 利用モード

各モードは組み合わせて利用できます。

### 問題

- **通常問題**：用意された問題に取り組みます。
- **項割当てクイズ**：三つの項をS・M・Pへ正しく割り当てます。
- **自由問題**：二つの前提を入力して独自の問題を作成します。ユーザー名詞も利用できます。

### 図

- **自動表示**：前提と結論の図を自動で表示します。
- **手動駒配置**：セル内や境界上へO／I駒を配置します。マウス、タッチ、キーボードに対応し、論理上の位置と駒の種類が正しい場合に次へ進めます。

### 結論

- **自動表示**：導かれる結論を自動で表示します。
- **結論クイズ**：A・E・I・O・「確定した結論なし」から回答します。正解するまで結論文と正解図は表示されません。手動駒配置と併用した場合は、結論への正解後に二文字図を操作できます。

手動配置と結論クイズの回答は永続保存されません。

## 自由問題の保存

複数の自由問題に名前を付け、ブラウザのlocalStorageへ保存できます。保存問題は開く・編集・削除が可能です。保存するのは安定ID、問題名、二つの前提だけで、S・M・P、結論、図は開くたびに再計算されます。保存問題でも各クイズと手動駒配置を利用できます。

ユーザー名詞一覧もlocalStorageへ保存されます。保存問題が参照しているユーザー名詞は、その問題を編集または削除するまで削除できません。作業中の未保存問題や回答状態は保存されません。

## チュートリアル

 `tutorial.html` では、S′・M′・P′が補集合であること、O・I・境界I、Barbaraの段階的配置、前提の統合、Mの消去と二文字結論図、手動配置の操作を説明します。ゲームと同様に`file://`から利用できます。

チュートリアルは現在のルイス・キャロル方式だけを扱い、第16段階の方式切り替えは実装していません。規則には確認できた原著の章節参照を表示し、原著に直接記載された規則、原著から整理・導出した説明、本アプリ固有の操作仕様を区別しています。章節番号を主、印刷ページを補助情報として扱います。対応関係は [tutorial-source-map.md](docs/tutorial-source-map.md) で管理し、未確認の章節番号は推測して追加しません。

## 必要環境

ゲームの利用にはブラウザのみが必要です。開発時には Node.js と npm が必要です。

動作確認には Google Chrome を使用しています。

## ゲームの起動方法

開発環境を用意したり、コマンドを実行したりする必要はありません。配布されたフォルダーを開き、`dist` フォルダー内の `index.html` をダブルクリックするとゲームが起動します。遊び方を確認する場合は、同じフォルダー内の `tutorial.html` をダブルクリックしてください。

## セットアップと開発 (エンジニア向け)

```sh
npm install
npm run dev
```

開発用 URL はコンソールに表示されます。TypeScript の変更は監視されますが、HTML または CSS を変更した場合は開発コマンドの再起動が必要な場合があります。

## 検証

```sh
npm test
npm run typecheck
npm run build
npm run check
```

`npm run check` は型検査、テスト、ビルドを順に実行します。

## 配布

`npm run build` で `dist/` に配布物を生成します。生成された `dist/index.html` と `dist/tutorial.html` をブラウザで直接開いて利用できます。外部ネットワークへの接続やローカルサーバーは不要です。
