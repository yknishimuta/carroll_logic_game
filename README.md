# ルイス・キャロルの論理ゲーム

ルイス・キャロルの図式を使い、二つの前提から導かれる結論を考えるブラウザゲームです。
固定前提の組み込み問題と、利用者が前提を作る自由問題を利用できます。どちらでも、結論を自動表示するかクイズにするかを設定から選べます。
日本語と英語の両方に対応しています。

## 利用モード

### 問題

- **組み込み問題**：固定された二つの前提を使用します。
- **自由問題**：利用者が二つの前提を入力します。ユーザーが登録した名詞も利用できます。

前提が現実に真か、常識に合うかは判定しません。自由問題では論理計算に必要な入力構造だけを検証します。S・M・Pの対応は図と論理計算の内部構造として表示しますが、正解として問う項割当てクイズはありません。

### 図

- **自動表示**：前提と結論の図を自動で表示します。
- **手動駒配置**：セル内や境界上へO／I駒を配置します。論理上の位置と駒の種類が正しい場合に次へ進めます。

問題種別は前提の供給方法だけを決めます。結論の表示は、組み込み問題・自由問題・保存済み自由問題のいずれでも「自動表示」または「クイズ」を選択できます。自動表示では、統合前提が完成するとそのまま結論段階へ進め、導出結果と結論図を表示します。クイズでは統合前提の完成後にA・E・I・O・「確定した結論なし」から回答し、正答するまで「結論」ボタンを無効にします。正答後も統合前提段階に留まり、利用者が「結論」ボタンを押して結論文と結論図へ進みます。手動配置と結論クイズ回答は永続保存されません。

## 自由問題の保存

複数の自由問題に名前を付け、ブラウザのlocalStorageへ保存できます。保存問題は開く・編集・削除が可能です。保存するのは安定ID、問題名、二つの前提だけで、S・M・P、結論、図は開くたびに再計算されます。保存済み自由問題にも、その時点で選択している結論モードが適用されます。

ユーザー登録名詞一覧もlocalStorageへ保存されます。ユーザー登録名詞はアプリ内の専用管理画面で追加・編集・削除し、ゲーム画面には登録件数と管理入口だけを表示します。管理画面を往復してもゲームの進行状態は維持されます。ユーザー登録名詞は現在の表示言語だけで登録でき、別言語の翻訳は任意です。翻訳がない場合は登録済み言語の表記をそのまま表示し、自動翻訳やローマ字化は行いません。英語は主語複数形と述語句を一組で登録します。翻訳不足でも保存問題は両言語で利用できます。保存問題が参照しているユーザー登録名詞は、その問題を編集または削除するまで削除できません。作業中の未保存問題や回答状態は保存されません。

## 必要環境

ゲームの利用にはブラウザのみが必要です。開発時には Node.js と npm が必要です。

動作確認には Google Chrome を使用しています。

## ゲームの起動方法

開発環境を用意したり、コマンドを実行したりする必要はありません。配布されたフォルダーを開き、`dist` フォルダー内の `index.html` をダブルクリックするとゲームが起動します。遊び方を確認する場合は、同じフォルダー内の `tutorial.html` をダブルクリックしてください。

## セットアップと開発 (エンジニア向け)

```sh
npm install
npm run dev
```

開発用 URL はコンソールに表示されます。TypeScript の変更は監視されますが、HTML または CSS を変更した場合は開発コマンドの再起動が必要な場合があります。

## 検証

```sh
npm test
npm run typecheck
npm run build
npm run check
```

`npm run check` は型検査、テスト、ビルドを順に実行します。

## 配布

`npm run build` で `dist/` に配布物を生成します。生成された `dist/index.html` と `dist/tutorial.html` をブラウザで直接開いて利用できます。外部ネットワークへの接続やローカルサーバーは不要です。
